# Absen Makan Meong 🐱
1. Ekstrak zip, buka folder di VS Code.
2. Buka `.env`, ganti DATABASE_URL dengan connection string Neon (copy persis dari dashboard Neon, ganti password).
3. Terminal: `npm install` lalu `npm start`
4. Buka http://localhost:3000 (user) dan http://localhost:3000/admin.html (admin).
Login admin default: admin / meong123 (ubah di .env). Tabel dibuat otomatis.
